# MCR-Bunny

AutoWheel là ứng dụng tự cuộn chuột độc lập cho Windows 10/11 64-bit.

- [Tải AutoWheel.zip (ứng dụng + mã nguồn)](https://github.com/hoangnguyen1804/MCR-Bunny/raw/refs/heads/autowheel-v1.0.0/downloads/AutoWheel.zip)
- [Tải AutoWheel.exe](https://github.com/hoangnguyen1804/MCR-Bunny/raw/refs/heads/autowheel-v1.0.0/downloads/AutoWheel.exe)
- [Hướng dẫn tiếng Việt](downloads/HUONG-DAN.md)
- [Mã nguồn và kiểm thử](autowheel/)

Mặc định: cuộn xuống, khoảng trễ yêu cầu 1 ms. Chuyển sang cửa sổ đích và nhấn **F6** để bật; thả rồi giữ chuột giữa để cuộn, thả để ngừng. **F8** tắt; **F10** thoát. Có thể chọn nút hông thay cho chuột giữa. Đổi cửa sổ sẽ tự tắt. Game cần hỗ trợ gán nhảy vào hướng cuộn tương ứng.

Ứng dụng dùng Windows SendInput, không truy cập bộ nhớ game, nạp DLL, can thiệp anti-cheat, cài driver hoặc yêu cầu Administrator. Đây không phải bản vượt Xigncode; không bảo đảm game chấp nhận thao tác hoặc không bị kick/ban.

Đã chạy 12 kiểm thử logic và kiểm tra EXE biên dịch chéo. Chưa chạy giao diện trên Windows hoặc kiểm thử trong game. 1 ms là khoảng trễ yêu cầu, không phải cam kết nhịp thực tế. EXE chưa ký số.

Mã SHA-256 có trong [downloads/SHA256SUMS.txt](downloads/SHA256SUMS.txt).
